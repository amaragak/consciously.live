# Affirmation loop

**What the sources share.** Nearly every session is built on short first-person present-tense declarations, usually "I am…", with space after each for the listener to repeat or absorb it. The sources split into two forms. Some are a pure list in which each line is said, then followed by a pause. Others are a framed session: a short welcome, a few breaths, a brief rationale, then an affirmation block, then a quiet close. The pure lists loop one set of lines many times, sometimes with a unison pairing ("I…/You…"). The framed sessions, especially the shorter ones, usually open with a few settling breaths before the affirmations begin.

**Phases.** Across the sources the common shape is arrival, then a rationale or intention, then affirmation block(s) that deepen through a theme, then silent absorption, then a close. Gratitude, worth, safety and abundance are the commonest themes.

**Pauses.** Short sessions use shorter pauses and long ones use many more. Pauses between lines range from about 1.5s to about 10s, and the gap grows when lines are longer or the listener is meant to repeat them. A single long silence of 3–8 minutes in some sources is a mantra or silent-repetition block.

**Poor fits.** The Louise Hay long-form talks (12 and 17) are mostly lecture. The "Flower Fresh" breathing meditation (21) is a gatha practice with very long silences. The mantra-sit sessions (6, 7, 10, 24) and the Moses Code session (25) are really silent mantra practices. The trauma-safety session (18) leans on breath pairing.
