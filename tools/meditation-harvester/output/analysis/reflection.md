# Reflection

**What the sources share:** The sessions share a settle-then-turn-inward arc. A short settling opening (posture, breaths, body) leads to a long middle where the listener is handed a prompt (a question, a memory, a phrase to repeat) and given time to answer silently. Closing is brief: a deepening breath, a return of attention, a carry-forward line.

**Where they differ:** There are three middle modes.
- Question-led inquiry: gratitude prompts, a difficult situation, "what does this part need?"
- Repeated phrases: gratitude or self-love affirmations, loving-kindness wishes, forgiveness recitations.
- Narrated imagery or teaching: a light bath, a visiting wise figure, a "mistake as stone" metaphor.

Lengths run from 5 to 46 minutes. Some sources are one long teaching talk.

**Phases seen:**
1. Settle (breath, body, permission)
2. Frame or intention
3. Prompt and reflection (a memory, a situation, or a gratitude list)
4. Embodiment (feel it in the body, hand on heart, warmth or light)
5. Phrase offering (affirmations or wishes)
6. Rest in the result
7. Return and carry forward

**Poor fits:** The awareness-inquiry session is closer to open-awareness. The positive-thinking session is mostly silence, a secondary fit. One long teacher session is largely lecture, with spoken content outweighing meditation. The abundance-affirmation session is closer to manifestation.

**Pauses:** The typical pause is about 2–3s, which fits short cues. Pauses after real questions and memory prompts stretch to 10–50s. The longest silences come late, once the listener is settled. Affirmation-only tracks use an even 6–7s after each line. Questions are almost never followed by short pauses.
